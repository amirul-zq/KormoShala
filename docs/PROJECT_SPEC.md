# 1. Project Overview

KormoShala is a web-based local worker marketplace built for Bangladesh.
It connects Hirers who need skilled workers with Workers looking for
jobs through a simple, modern and user-friendly platform.

The system allows Hirers to post jobs, Workers to browse and apply for
those jobs, Hirers to select applicants, complete jobs and leave
reviews. An administrator manages the overall platform through a
dedicated Admin Panel.

The project is developed using Laravel, Blade, Tailwind CSS and MySQL.
